atpg

atpg is a gate-level Automatic Test Pattern Generation tool for combinational digital circuits, built on slang for its SystemVerilog frontend.

It takes a hierarchical design built from SystemVerilog gate primitives, flattens it into a gate-level netlist, derives the stuck-at fault list, and produces a set of input vectors that detects those faults - together with the response each vector should produce. The result can be written as an IEEE 1450 STIL program for a tester flow.

The pipeline

Each stage is a separate module, and each consumes the previous stage's output:

  • atpg::frontend flattens SystemVerilog into a gate netlist.
  • atpg::ir holds that netlist as a levelized graph.
  • atpg::sim evaluates it for one input vector.
  • atpg::fault enumerates and collapses the stuck-at fault list.
  • atpg::gen generates a test per fault class using a SAT-based miter construction, or proves the fault redundant.
  • atpg::fsim fault-simulates a pattern set bit-parallel to report coverage.
  • atpg::compact shrinks a pattern set to an irredundant subset with identical coverage.
  • atpg::stil renders the result as a STIL program.

Features

  • Fault collapsing by local equivalence and the checkpoint theorem.
  • SAT-based test generation on OR-Tools CP-SAT, which proves redundancy rather than merely failing to find a test.
  • A generate-and-drop loop that fault-simulates each pattern to skip the solver for faults it already covers.
  • Bit-parallel fault simulation, 64 patterns per machine word, with each fault re-simulated only over its own fanout cone.
  • Greedy pattern compaction producing an irredundant vector set.
